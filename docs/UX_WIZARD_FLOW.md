# DesignBridge 新 UX 流程

> 分步 Wizard + 雙入口；整體／局部由 Design Director 判斷，前端不選 routing。

## 原則

- 不拆「從零／改造」→ Step 1 用**有無空間照片**區分即可。
- Step 2 寫需求，Step 3 選風格；**僅 Step 3 選「從圖庫挑」時**才呼叫風格向量搜尋。
- 移除改動幅度 Slider；`edit_scope` 由情境帶預設值（見文末）。
- 「指定區域修改」= 畫遮罩的 inpaint，與語意微調（DD 自動）分開。

---

## 入口

| 入口 | 流程 |
|------|------|
| **設計 Wizard** | 預設首頁；3 步表單 → 生成 |
| **指定區域修改** | 生成完成後，於結果區按鈕進入 → 畫遮罩 → 需求 → 生成（`refine_mode: true`）；左欄可「返回設計流程」 |

歷史紀錄 FAB 保留。頂部不再提供雙模式切換。

## Wizard 四步

底部：**上一步** / **下一步**（Step 4 為 **生成設計圖**）。

### Step 1 — 空間

| 欄位 | 說明 |
|------|------|
| 空間類型 | chips：客廳、臥室、書房、廚房、浴室、全室／其他 |
| 坪數 | chips：`<10`、`10–20`、`20–30`、`30+`|
| 空間照片 | **選填**；上傳區標示「選填」即可，不提供「略過」按鈕；未上傳可直接下一步 |

右側：有圖顯示預覽；無圖可留白或簡短說明（例：「尚未上傳照片」）。**不**顯示風格推薦。

### Step 2 — 需求與限制

| 欄位 | 說明 |
|------|------|
| 設計需求 | textarea（建議必填） |
| 家庭結構 | 選填 chips |
| 風水需求 | 選填 chips |

**不**即時搜尋風格。右側僅提示文案。

### Step 3 — 風格（可略過）

三選一（互斥），切換時清除其他路徑選擇：

| 路徑 | 說明 |
|------|------|
| ① 選風格類別 | 下拉／卡片；可不搜尋向量 |
| ② 從圖庫挑 | 依「搜尋用描述」搜尋 → 選參考圖；右側顯示候選（6 張，可換一批） |
| ③ 上傳參考圖 | 上傳後選套用方式 |
| 略過 | 不套用風格參考 |

**② 搜尋用描述**（可編輯）預填：`{空間類型} {坪數} {Step2 需求}`，按「搜尋」才打 API。

有參考圖後才顯示套用方式：AI 分析（預設）／ Redux／ IP-Adapter。

回 Step 2 改需求後再進 Step 3：更新預填、清除已選風格，② 需重新搜尋。

### Step 4 — 確認與生成

左欄摘要：空間、需求、家庭／風水、風格來源（或「未套用」）。

右側生成後：`ResultPanel` + **AI 判斷**白話（`design`→整體設計，`design_adjuster`→局部微調）。

生成後可點結果區 **指定區域修改**（帶入本次生成圖）。

---

## 指定區域修改

上傳圖、遮罩、需求皆必填 → 生成。不經風格 Wizard。

---

## 版面

- 左：Logo、Tab、步驟指示、當步表單、上一步／下一步。
- 右：Step 1–2 提示／預覽；Step 3 且 ② 為風格候選；完成為結果。

|------|----------------|
